# エスパー ESPER (Ejecta Spectro-Photometry analyzER) — 操作マニュアル

衝突実験で撮影した Phantom の分光動画（0次光＋1次分光像）から、イジェクタ（破片）の並進速度・自転周期・
灰色体温度・サイズを求めるソフトウェア ESPER v3.1 の操作マニュアルです。

- マニュアル（画像つき）：[index.html](index.html)（GitHub Pages を有効にすると https://nu-sx.github.io/ESPER/ で表示できます）
- 動画マニュアル（音声・字幕つき、6 分 12 秒）：[video/esper_manual_720p.mp4](video/esper_manual_720p.mp4)・
  [1080p](video/esper_manual.mp4)・[字幕](video/esper_manual.srt)

このリポジトリにはマニュアルだけを置いています。ソフトウェア本体（macOS の dmg、Windows のインストーラ）と
ソースコードは公開していません。
